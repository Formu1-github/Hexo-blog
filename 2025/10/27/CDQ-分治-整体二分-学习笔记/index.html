CDQ 分治/整体二分 - 学习笔记

前

来源：oi-wiki

cdq 分治其实是一种思想，或者说，一种迎合其他算法的处理方式。不过 cdq 是离线算法，有使用的限制。

cdq 分治的应用大致分为三类：

  1. 解决与点对相关的问题

  2. 一维动态规划的转移

  3. 化动为静

与点对相关

这类问题多数类似于「给定一个长度为 nnn 的序列，统计有一些特性的点对 (i,j)(i,j)(i,j) 的数量」或「给定一个长度为 nnn 的序列，找到一对点 (i,j)(i,j)(i,j) 使得一些函数的值最大」。

cdq 通过每次递归将序列分为两个子问题，单个问题内只处理跨区间的结果。

过程如下：

  1. 找到序列中点 midmidmid

  2. 此时点对 (i,j)(i,j)(i,j) 可以被分为三类：

    • l≤i≤mid,mid+1≤j≤rl\leq i\leq mid,mid+1\leq j\leq rl≤i≤mid,mid+1≤j≤r

    • l≤i,j≤midl\leq i,j\leq midl≤i,j≤mid

    • mid+1≤i,j≤rmid+1\leq i,j\leq rmid+1≤i,j≤r

  3. 处理第一类点对

  4. 将整个序列拆成 [l,mid][l,mid][l,mid] 和 (mid,r](mid,r](mid,r] 以处理剩下两类情况

  5. 递归下去

可以发现这样操作会使得任意一个点对都能够在某次问题中被解决。

在理解中可以与 cdq 分治与归并排序做类比。事实上用归并排序求逆序对的过程就是下面要讲到的「偏序点对计数」。

例题

【模板】三维偏序（陌上花开）

cdq 分治经典问题——偏序点对计数。即统计点对 (i,j)(i,j)(i,j) 的数量，使所有 aj,xa_{j,x}aj,x​ 和 ai,xa_{i,x}ai,x​ 均满足一定偏序关系。

那么很显然上面用归并排序求逆序对就是一个二维偏序：统计 (i,j)(i,j)(i,j)，使 i<ji<ji<j 且 ai>aja_i>a_jai​>aj​。

我们来想一下如何拓展到三维偏序上。

首先将序列按 aaa 排序。

假设我们现在写好了 solve(l,r)，并且通过递归搞定了 solve(l,mid) 和 solve(mid+1,r)。现在我们要做的，就是统计满足 l≤i≤midl\leq i\leq midl≤i≤mid，mid+1≤j≤rmid+1\leq j\leq rmid+1≤j≤r 的点对 (i,j)(i,j)(i,j) 中，有多个点对还满足 bi≤bjb_i\leq b_jbi​≤bj​，ci≤cjc_i\leq c_jci​≤cj​ 的限制条件。

为了方便枚举，我们把 [l,mid][l,mid][l,mid] 和 (mid,r](mid,r](mid,r] 中的点全部按照 bbb 的值从小到大排个序。之后我们依次枚举每一个 jjj， 把所有 bi≤bjb_i\leq b_jbi​≤bj​ 的点 iii 全部插入到某种数据结构里（这里我们选择树状数组）。此时只要查询树状数组里有多少个点的 ccc 值是 ≤cj\leq c_j≤cj​ 的，我们就求出了对于这个点 jjj，有多少个 iii 可以合法匹配它了。显然把 iii 插入的操作使用一个指针同步扫即可。

 点击折叠

联想一下二维偏序的求法，有两种：一种是归并排序，一种是树状数组。而三维偏序就像是把这两个东西结合在了一起。

通过这样的流程，我们就成功在 O(nlog⁡2n)O(n\log^2 n)O(nlog2n) 的复杂度内完成了算法。

[CQOI2011] 动态逆序对

仔细推一下。令 TiT_iTi​ 表示 iii 删除的时间。

考虑每个点删掉之后对答案的影响，然后累加至答案。会影响到答案，且不重复计算的情况为：

  1. Ti<TjT_i<T_jTi​<Tj​ ，且 i<ji<ji<j，ai>aja_i>a_jai​>aj​。

  2. Ti<TjT_i<T_jTi​<Tj​ ，且 j<ij<ij<i，aj>aia_j>a_iaj​>ai​。

然后就套三维偏序板子即可。

优化一维 dp 的转移

1D/1D 动态规划指的是一类特定的 DP 问题，该类题目的特征是 DP 数组是一维的，转移是 𝑂(𝑛) 的。如果条件良好的话，有时可以通过 CDQ 分治来把它们的时间复杂度由 𝑂(𝑛2) 降至 𝑂(𝑛log2⁡𝑛)。

例如，给定一个序列，每个元素有两个属性 𝑎，𝑏。我们希望计算一个 DP 式子的值，它的转移方程如下：

𝑑𝑝𝑖 =1 +max𝑖−1𝑗=1𝑑𝑝𝑗[𝑎𝑗 <𝑎𝑖][𝑏𝑗 <𝑏𝑖]

这是一个二维最长上升子序列的 DP 方程，即只有 𝑗 <𝑖,𝑎𝑗 <𝑎𝑖,𝑏𝑗 <𝑏𝑖 的点 𝑗 可以更新点 𝑖 的 DP 值。

直接转移显然是 𝑂(𝑛2) 的。以下是使用 CDQ 分治优化转移过程的讲解。

我们发现 𝑑𝑝𝑗 转移到 𝑑𝑝𝑖 这种转移关系也是一种点对间的关系，所以我们用类似 CDQ 分治处理点对关系的方式来处理它。

这个转移过程相对来讲比较套路。假设现在正在处理的区间是 (𝑙,𝑟)，算法流程大致如下：

  1. 如果 𝑙 =𝑟，说明 𝑑𝑝𝑟 值已经被计算好了。直接令 𝑑𝑝𝑟 + + 然后返回即可；

  2. 递归使用 solve(l,mid)；

  3. 处理所有 𝑙 ≤𝑗 ≤𝑚𝑖𝑑，𝑚𝑖𝑑 +1 ≤𝑖 ≤𝑟 的转移关系；

  4. 递归使用 solve(mid+1,r)。

第三步的做法与 CDQ 分治求三维偏序差不多。处理 𝑙 ≤𝑗 ≤𝑚𝑖𝑑，𝑚𝑖𝑑 +1 ≤𝑖 ≤𝑟 的转移关系的时候，我们会发现已经不用管 𝑗 <𝑖 这个限制条件了。因此，我们依然先将所有的点 𝑖 和点 𝑗 按 𝑎 值进行排序处理，然后用双指针的方式将 𝑗 点插入到树状数组里，最后查一下前缀最大值更新一下 𝑑𝑝𝑖 就可以了。
