Array Gift - 题解

声明：本文使用 deepseek 参与编写

2024“钉耙编程”中国大学生算法设计超级联赛（5）

B 题。

给定一个长度为 nnn 的正整数序列 aaa。每次可以执行两种操作之一：

  1. 选择不同的下标 i,ji,ji,j，且 aj≠0a_j \neq 0aj​=0，令 ai←ai mod aja_i \leftarrow a_i \bmod a_jai​←ai​modaj​。
  2. 选择某个下标 iii 和任意正整数 xxx，令 ai←ai+xa_i \leftarrow a_i + xai​←ai​+x。

目标：经过若干次操作后，序列中恰好只剩下一个非零数，其余全部为 000。求最小操作次数。

数据范围：T≤30, n≤100, ai≤106T \le 30,\ n \le 100,\ a_i \le 10^6T≤30, n≤100, ai​≤106。

首先拿到这道题，显然先从小到大排个序。

喜闻乐见的，分类讨论题还是要把思维链的结构写出来。所以我加几个标题

1. 上下界

观察容易发现，考虑最小的操作次数一定是理想情况下使用一个值去全部模掉其他值，总的操作次数为 n−1n-1n−1。

接着可以很简单的想到一个一定可以的方案：

  1. 构造两个差为 111 的数。通过将小的数补齐至大的数-1实现

  2. 将两个数模一下得到 111

  3. 对其他所有数统一进行  mod 1\bmod 1mod1 操作，需要 n−1n-1n−1 次操作

因此我们得出了上界为 n+1n+1n+1。

所以说可能的答案区间为 [n−1,n+1][n-1,n+1][n−1,n+1]。

2. 可以被直接消去的数

如果存在某个 aja_jaj​ 使得：

ai mod aj=0a_i \bmod a_j = 0 ai​modaj​=0

那么一次操作 111 就可以把 aia_iai​ 变成 000。
这样的 aia_iai​ 称为“可以直接消去的数”。

因此，我们可以先把所有“能被其他某个数整除”的数筛掉。
它们每一个只需要一次操作就能变成 000，不会增加额外代价。

3. 考虑不能互相消去的数

这里我们定义：

  • n 保存原长度 nnn；

  • “关键数”是“不能互相消去的数” （“关键”在只有这些数会影响答案）；

  • 设关键数集合为 AAA，大小为 mmm。

  • modexpr() 负责筛选，并把他们放回 a，此时使用 m 存放新的长度 mmm。

这里不能互相消去的数情况有以下几种：

情况 0：m=0m = 0m=0

所有数都能被其他数整除。
任选一个数保留，其余 n−1n-1n−1 个数各一次操作变成 000。
答案：

n−1n-1 n−1

计算所有关键数的最大公约数：

G=gcd⁡(A)G = \gcd(A) G=gcd(A)

如果 GGG 本身就在关键数集合中，那么所有关键数都是 GGG 的倍数。
保留 GGG，其他关键数一次模 GGG 变成 000。
被筛掉的数也能被 GGG 整除，同样一次消去。
总操作次数仍为：

n−1n-1 n−1

如果存在 m>1m>1m>1 且 gcd⁡(A)∈A\gcd(A) \in Agcd(A)∈A，那么对所有除了 GGG 的关键数尝试  mod gcd⁡(A)\bmod \gcd(A)modgcd(A) 后仍能继续消去，与前面“不能互相消去”的前提条件不符。

所以可以将情况 0,1 合并成：

情况 2：G∉AG \notin AG∈/A，但可以用 mmm 次操作处理关键数

此时不能直接保留 GGG，因为 GGG 不是现有非零数。
但我们可以通过一次操作 111 产生一个“工具数”，使得其余关键数都能被这个工具数整除。
这样处理 mmm 个关键数需要：

  • 1 次操作产生工具数；

  • m−1m-1m−1 次操作消去其余关键数。

总共 mmm 次。
加上被筛掉的 n−mn-mn−m 个数，总操作次数为：

(n−m)+m=n(n-m) + m = n (n−m)+m=n

代码中通过三个 check 来判断能否用 mmm 次操作处理关键数。

2.1 check2()

含义：
枚举某个关键数 aja_jaj​，计算除它以外所有关键数的 gcd⁡\gcdgcd，记为 GsG_sGs​。
如果满足以下任一条件：

  1. 存在某个其他关键数（即 i≠ji\neq ji=j），使得 ai=Gsa_i=G_sai​=Gs​；

  2. aj≤Gsa_j \le G_saj​≤Gs​；

则说明可以通过

  1. 一次对 aja_jaj​ 的加操作，使得存在一个合适的工具数能消去 aja_jaj​。

  2. 一次对 aja_jaj​ 的加操作，产生一个合适的工具数，使得其余数都能被消去。

于是总操作次数为 nnn。

2.2 check3()

如果存在两个关键数，一个模另一个余 111：

ai mod aj=1a_i \bmod a_j = 1 ai​modaj​=1

那么一次操作就可以产生 111。
有了 111 之后，所有数都可以模 111 变成 000。
总操作次数：

1+(m−1)=m1 + (m-1) = m 1+(m−1)=m

加上被筛掉的数，总代价为 nnn。

2.3 check4()

这是更一般的情况。
对于某个 aia_iai​，计算除它以外所有关键数的 gcd⁡\gcdgcd，记为 GsG_sGs​。
如果存在 aja_jaj​ 使得：

r=ai mod aj≠0r = a_i \bmod a_j \neq 0 r=ai​modaj​=0

且：

Gs mod r=0G_s \bmod r = 0 Gs​modr=0

即 rrr 整除 GsG_sGs​，那么 rrr 就能整除除 aia_iai​ 外的所有关键数。
我们可以用 ai mod aja_i \bmod a_jai​modaj​ 得到 rrr，把 aia_iai​ 变成 rrr，然后其他数一次模 rrr 变成 000。
总操作次数仍为 mmm，总代价 nnn。

情况 3：以上都不满足

如果无法用 mmm 次操作处理关键数，则至少需要 m+1m+1m+1 次。
加上被筛掉的数，总操作次数为：

(n−m)+(m+1)=n+1(n-m) + (m+1) = n+1 (n−m)+(m+1)=n+1

也就是前文提到的上界。
